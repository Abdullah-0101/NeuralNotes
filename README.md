🧠 Alsalem Neural-Notes
Alsalem Neural-Notes is a professional-grade, full-stack AI study platform that transforms complex text and images into interactive, bilingual flashcards. Designed to optimize the learning process, it leverages the Gemini 1.5 Flash model to provide high-speed, multi-modal content generation for students.

🚀 Key Features
Multi-Modal AI (OCR): Users can upload images of textbook pages, handwritten notes, or diagrams. The system performs Optical Character Recognition to extract core concepts and generate relevant study material.

Bilingual Intelligence: Includes a native toggle to generate content in either English or Arabic, catering specifically to regional educational needs.

Interactive Smart Quiz Mode: Enhances active recall through a custom-built interface where users flip cards using smooth 3D CSS animations to reveal answers.

Professional Export Suite: Users can export their generated sessions as Anki-ready CSVs or formatted PDFs, allowing for seamless integration into long-term study workflows.

Secure Infrastructure: Developed with security best practices, utilizing environment variables and proper Git protocols to protect sensitive API configurations.

🛠️ Technical Stack
Frontend: HTML5, CSS3 (3D Transforms & Flexbox), JavaScript (Async/Await & Fetch API).

Backend: Python with FastAPI (High-performance API framework).

AI Engine: Google Gemini 1.5 Flash (Large Language Model).

Infrastructure:

Vercel: Frontend Hosting and Deployment.

Render: Backend API Service and Environment Management.

GitHub: Version Control and CI/CD Pipeline.
